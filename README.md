# To-Do App — Aplicación de tareas pendientes

## Descripción

To-Do App es una aplicación de escritorio para administrar tareas pendientes.
Permite al usuario crear, completar, editar y eliminar tareas, además de
consultar las tareas pendientes y completadas.

El proyecto será desarrollado para la materia de Ingeniería de Software.

## Objetivo

Desarrollar una aplicación sencilla que permita organizar tareas pendientes
mediante una interfaz gráfica fácil de utilizar.

## Funcionalidades

- Crear tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Editar tareas.
- Filtrar tareas por estado.
- Mostrar fecha de creación.
- Guardar y cargar las tareas.

## Gestión del proyecto

El proyecto será gestionado mediante GitHub Projects utilizando un tablero
Kanban para organizar y visualizar el avance de las tareas.

## Estructura del proyecto

La estructura del proyecto será definida durante el desarrollo y estará
organizada para separar la interfaz, la lógica de las tareas y el
almacenamiento de información.
